# contextual-3d-mapping

Research framework for building open-vocabulary 3D semantic and contextual maps from RGB and LiDAR, combining visual-language features, semantic memory, scene graphs, and spatial reasoning.

## Documentation

Repository-level architecture and integration documentation is available in [`docs/index.md`](./docs/index.md).

Detailed implementation documentation will live inside each module under `modules/<module>/docs/` as those modules are developed.
